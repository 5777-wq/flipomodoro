为什么是它

把该做好的做好，
其他的一概不做。

没有账号体系，没有社交，没有广告，也没有"开通会员解锁"。它只回答一个问题：这 25 分钟，你专注了吗。

到点提醒，精确到秒

专注开始那一刻就向系统注册精确闹钟（setAlarmClock），Doze 省电不迟到、不静默；锁屏全屏提醒，通知上直接「开始下一阶段」。倒计时走完自动转加时正计时，超出部分也计入专注。

多元统计图表

趋势折线、任务占比饼图、任务排行、24 小时时段热图、星期分布——五种视角 × 7/30/90 天范围，每一次专注都会出现在最近记录里。

数据只在手机里

不要任何网络权限，连 INTERNET 权限都没有。备份导出 JSON / Markdown，换机随时带走；恢复前自动留底，可回滚。

任务随你定义

添加、改名、删除、归档；给每个任务设专属专注时长与预估番茄数。不建任务也照常统计，记作「自由专注」。

全屏翻页时钟

纯黑底机械翻页卡片，带中缝与翻落动画。计时中显示剩余时间，空闲时就是一面床头钟，屏幕常亮。

白噪音

雨声、傍晚咖啡馆，全部由 WebAudio 实时合成，一个音频文件都不带。伴随专注自动播放，暂停即停。

看得见的坚持

统计不该是谁的附庸，
它本身就是主页。

  • 每日目标进度环 + 连续天数，先把今天的士气立起来
  • 五种图表随时切换，7 / 30 / 90 天一键换范围
  • 「最近记录」列出每一次专注——有没有建任务，都算数
  • 文字洞察：最高效时段、活跃日均、本周 vs 上周
  • 图表全部手写 SVG，零图表库，APK 依旧 4MB
  • 点任务名就地展开编辑器：名称、专注时长、预估、优先级
  • 为某个任务专注，完成后自动 +1，超预估转青灰提示
  • 删除、归档、勾选完成，一切由你说了算
  • 优先级排序：要紧的永远在列表最上面

床头钟

夜里的时间，
就该这样翻页。

点一下右上角，进入纯黑全屏。数字卡带着机械中缝翻落，OLED 屏幕上安静得像什么都没发生。计时模式显示剩余时间，空闲时显示当前时间。

  • 点击任意处唤起退出钮，3 秒自动隐去
  • 打开期间屏幕常亮，状态栏自动隐藏
  • 尊重系统「减弱动效」设置

现在开始

两分钟，装好你的第一个番茄。

下载最新版 APK

也可以到 Releases 页挑选历史版本， 或直接从源码构建：git clone → npm install → npm run apk

  1. 下载 APK 到手机（约 4MB）
  2. 点开安装，允许「来自未知来源」——因为不走应用商店
  3. 打开即用：先点「开始」，完成第一个番茄
